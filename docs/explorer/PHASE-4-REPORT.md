## Limits

This is a linked parts-and-relationships inspector, not a draggable graph canvas or runtime debugger. Relationships are curated and require maintenance. Source text is inspectable with resolved symbol lines but the drawer has no syntax-aware editor. Mobile verification covered the selected system view, not exhaustive accessibility. The UI gallery remains Phase 5; broad acceptance and Groundwork extraction remain later work. Historical Phase 3 evidence retains its original scope.

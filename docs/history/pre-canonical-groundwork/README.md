# Groundwork schema runtime

Normal commands require Node 22+ and Git. They use the committed validators.cjs; no runtime npm installation or model call is required.

schemas/ is the authoritative JSON Schema source. validators.cjs is generated by Ajv 8.17.1 and bundled with esbuild 0.25.10. runtime.mjs checks the schema digest and refuses stale generated validators. AJV-LICENSE accompanies the bundled Ajv runtime. Build dependencies are pinned in package-lock.json and are development-only.

To change schemas, from this directory:

```sh
npm ci --ignore-scripts
npm run build
```

Review the schema and generated-code diff together, then run `node --test scripts/check-docs.test.mjs` from the repository root. node_modules is locally ignored. Do not hand-edit generated validator functions. Freshness hashes include the runtime modules, schemas and bundled validators.

The validators enforce field contracts. Repository and guidance modules enforce paths, accepted-source selection, existing files, actual changes and freshness. None authenticates an approval or certifies narrative truth.
